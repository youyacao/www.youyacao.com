## Project Overview

This repository is the **front-end source code** of the official website of **Chengdu Yike Youyacao Technology Co., Ltd.** (Youyacao Tech). It is **static only** (HTML + CSS + JavaScript), making it easy to deploy, modify, and reuse.

### Tech Stack and Features

- **Static only**: No server-side dependency; can be deployed to any static host or CDN.
- **Tailwind CSS**: Responsive layout and theming, including light/dark mode.
- **Modern front-end**: Glassmorphism, gradients, animations, and accessibility considerations.
- **Multi-device**: Desktop and mobile friendly, with mobile navigation and touch-friendly UI.

## How to Use

1. **Clone or download**
   ```bash
   git clone https://gitee.com/youyacao/www.youyacao.com.git
   cd www.youyacao.com
   ```
2. **Preview locally**  
   Open `index.html` in a browser, or use any static server (e.g. `npx serve .`, VS Code Live Server).
3. **Deploy**  
   Upload the directory to any static host (Nginx, OSS, Vercel, GitHub Pages, etc.) and set the root or `index.html` as the index.
4. **Modify and reuse**  
   You may modify content and layout in line with the [LICENSE](LICENSE). Commercial use requires a commercial license; see [LICENSE](LICENSE) and [zhengban.youyacao.com](https://zhengban.youyacao.com).
