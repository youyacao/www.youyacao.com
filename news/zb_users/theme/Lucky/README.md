## 其它说明

如果更新主题后网站出现错位问题，请检查：
- Ctrl+F5（强制刷新），因为有时候会修改CSS样式或者JS等，即使更新主题后本地还是存在之前的文件，其实也就是缓存，所以会出现错位问题；
- 如果你的网站有打开360CDN加速或者百度CDN加速或者其他CDN加速，请对应的登录后台更新缓存。
- 以上两种方法仍然无法解决你的问题，请通过QQ联系我。
